# tally-fonts

The two web font files used by the custom CSS on [tally-sa.com](https://tally-sa.com): The Year of The Camel, Regular (400) and Bold (700).

They are served through jsDelivr and pinned to a release tag, so the files never change under the store:

- https://cdn.jsdelivr.net/gh/kholoudboutari-ship-it/tally-fonts@v1.0.0/camel-400.woff2
- https://cdn.jsdelivr.net/gh/kholoudboutari-ship-it/tally-fonts@v1.0.0/camel-700.woff2
